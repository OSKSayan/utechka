# Утечка

Стартап из Казахстана: сервис находит, куда утекают деньги по подпискам. Он читает банковскую выписку и показывает забытые подписки, пробные периоды за 1 ₸, которые стали платными, тихие подорожания и дубли (например, три онлайн-кинотеатра сразу).

**Сайт:** https://osksayan.github.io/utechka/

## Что есть на странице

- **Рабочий MVP.** Загрузите PDF-выписку Kaspi или Halyk либо CSV-файл, и детектор найдёт регулярные платежи, отметит утечки и подскажет, как их отменить. Для пробных периодов есть готовая претензия на возврат.
- **Питч.** Проблема, рынок Казахстана (TAM / SAM / SOM), монетизация, конкуренты, риски.
- **Калькулятор юнит-экономики** с ползунками.
- **Роадмап** и план на первые 30 дней.
- **Три языка:** русский, казахский, английский.

## Приватность

Выписка обрабатывается в браузере и никуда не отправляется. В этой версии сайта ничего не сохраняется. Личный кабинет с сохранением разборов работает в версии на claude.ai.

## Как устроено

Один файл `index.html` без сборки и зависимостей: HTML, CSS и JavaScript. Шрифты подключаются с Google Fonts.

Цифры рынка и экономики являются допущениями для проверки, а не фактами.
